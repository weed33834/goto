Field Notes · v1.2.0 · 2026-07

TaskFlow

一个本地优先、端到端加密、跨平台的任务工作流。你的待办不必交给别人保管—— 数据在你的设备上，同步在你信任的设备间进行。

v0.0.1 测试 611 项全绿 Web 应用 + 自托管中继 两轮安全审计

01它解决什么

市面上的任务管理工具大致分两类：一类是纯本地待办，单机好用但换设备就抓瞎； 一类是云同步，方便却把你的每一项计划、习惯、笔记都放进别人服务器。 TaskFlow 选第三条路——数据默认在本地，跨设备同步时端到端加密， 中继服务只搬运密文，看不到任何内容。

这不是因为我们做不出云同步，而是任务管理这件事没必要把你的生活细节 交给第三方保管。代价是多花了不少功夫在加密协议和冲突解决上，换来的是： 没有 TaskFlow 账号这回事，也没有人能从服务器读出你的待办。

当前形态:浏览器 Web 应用(Vite + React 18)、可选的 Python 后端、可自托管的 Node 中继。 同步协议两端字节级互通。

02三个组件,一种数据

Web 应用 Vite · React 18 · Zustand 4
8 个页面 + 时间织锦视图。IndexedDB 本地存储 + Web Crypto 字段级 AES-256-GCM。隐私外壳 + 修改主密码 + 危险区数据销毁。
中继 Relay Node.js · WebSocket · 自托管

Web 应用 ⇄ Web 应用:端到端加密 P2P,中继仅作穿墙搬运工,全程不解密。

03端到端加密同步

这是项目里花时间最多的一块。两台设备同步前先握手，互相验明身份， 协商出一对方向隔离的会话密钥，之后所有记录都用 AES-256-GCM 加密。 中继看到的只是密文字节流。

身份层
每台设备一对 Ed25519 长期密钥，私钥存 Keychain / Keystore。设备 ID = sha256(原始公钥) 前 16 hex。
握手层
X25519 临时密钥做 ECDH，双方对 deviceId ‖ peerDeviceId ‖ nonce ‖ peerNonce ‖ ecdhPub 做 Ed25519 签名，防中间人。
派生层
HKDF-SHA256 从 ECDH 共享密钥派生 sendKey / receiveKey，info 按角色方向绑定：taskflow-sync-v1|initiator→responder。
记录层
同步主密钥（SMK）做 AES-256-GCM 对称加密。线格式 iv[12] ‖ authTag[16] ‖ ciphertext，IV 每次随机。
冲突层
先比 updatedAt（last-write-wins），时间戳相等时用版本向量做因果偏序判定，判定为 concurrent 时按策略收口。
传输层
9 种消息类型，帧格式 mode[1] ‖ length[4 BE] ‖ payload。重放保护用序列号 + 滑动窗口，握手 30s 超时。

Web 应用统一用 Web Crypto API,线格式 AES-GCM 的 authTag 位置做了显式对齐, 跨设备字节级互操作已用 611 项测试中的双向用例验证——一台设备加密的帧 另一台能解,反之亦然。
(截至 2026-07-20,测试总数 611 项:Web unit 494 + 26 skipped | Web e2e 108 | 后端 104 | Relay 9,覆盖同步协议、备份加密、冲突解决、配对握手等。)

04隐私不是开关,是默认

  • 本地优先存储:Web 应用数据落 IndexedDB,密钥经 PBKDF2-SHA256 600k 迭代派生,主密码不存盘,仅以 verifier 形式保存。
  • 字段级加密:保险库敏感字段叠加 AES-256-GCM,带密码生成器。
  • 密码错误 cooldown:连续 3 次错误密码后强制 30 秒锁定,防暴力枚举。
  • 修改主密码:设置页可在线修改主密码,验证旧密码 → 写新 verifier → 清空密钥缓存。
  • 剪贴板自动清除:复制保险库字段后默认 30 秒自动清除,可配置时长,复制按钮显示倒计时。
  • 自动锁屏:可设置 0 / 1 / 5(默认) / 15 / 30 / 60 分钟无操作自动锁定,或窗口失焦立即锁。
  • 隐私外壳:启动锁、自动锁屏、隐私模式、剪贴板清空、快捷键浮层(`?` 触发)。
  • 危险区数据销毁:清空数据(保留主密码与备份) / 恢复出厂设置(删主密码,重启到首次安装状态),二次确认,不可撤销。

两轮独立安全审计（TF-001~019、TF2-001~017）覆盖 CORS、密钥熵、备份元数据、 LLM 脱敏、API token 注入等，大部分已修复，剩余项在路线图跟踪。

06能看到什么

Web 应用提供 8 个页面 + 时间织锦视图,基于同一份数据,按场景切换:

  • Today — 今日 / 逾期 / 即将到期 / 全部四个 tab,空态文案分类定制。
  • Calendar — 月历视图,任务按截止日期分布。
  • Projects / Categories / Tags — 三层组织维度,支持颜色与图标。
  • Search — 全文搜索任务标题与描述,带搜索历史。
  • Vault — 加密保险库,字段级 AES-256-GCM,复制后定时清剪贴板。
  • Mosaic — 时间织锦,每日落砖,Canvas 渲染,悬停高亮。
  • Settings — 安全 / 外观 / 快捷键 / 数据 / 同步 / 危险区六分区。
  • 任务依赖 — blockedBy / blocks,被阻塞的任务不让你点完成。
