# Support

Thanks for using Goto! This page routes you to the right channel
depending on what you need.

## Quick answers

- **Usage questions** — read the [FAQ](FAQ.md) first; most common questions are already covered.
- **Roadmap & status** — see [docs/ROADMAP.md](docs/ROADMAP.md) for what's done and what's
  next.
- **Architecture deep-dive** — [ARCHITECTURE.md](ARCHITECTURE.md)
  walks through the state model and the E2EE sync protocol stack.

## Reporting issues

Open an issue on [GitCode](https://gitcode.com/badhope/goto/issues)
using one of the templates:

- **Bug** — something is broken or behaves wrong.
- **Feature request** — a new capability or improvement.
- **Question** — anything that's not a bug or a feature.

Before opening, please search existing issues to avoid duplicates.

## Security vulnerabilities

**Do not open a public issue for security vulnerabilities.**

Follow the private disclosure process in [SECURITY.md](SECURITY.md)
(email the maintainer directly). We aim to respond within 7 days and
release a patch within 30 days for confirmed vulnerabilities.

## Community

There is no official chat yet. If you want to discuss the project,
open a [Discussion](https://gitcode.com/badhope/goto/discussions) on
GitCode.

## Contributing

Pull requests are welcome! See [CONTRIBUTING.md](.github/CONTRIBUTING.md)
for the workflow, code style, and PR review process.

## Sponsorship

If Goto saves you time and you'd like to support development, see
[GitHub Sponsors](https://gitcode.com/badhope) or the Sponsor button
on the repo page.

## Maintainer response time

This is a solo-maintained project. Expect a response within:

- Issues: 7 days
- PRs: 14 days
- Security reports: 7 days

If you don't hear back, please ping the issue politely — sometimes
notifications get lost.
